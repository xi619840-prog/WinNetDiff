This source revision fixes GUI-01/02/03. Normal exports redact directly; full evidence requires a separate acknowledged action that Enter/Escape/window close cannot accept. Saving requires an existing initial folder or deliberate selection, explicit overwrite and atomic publication. Diagnosis clearly distinguishes completed, cancelled, failed and partial evidence and permits a new scan after the bounded worker exits.

The modular source and generated Python remain version 2.2.0a3. F5/F6/F7 and prior safety fixes are preserved. Current Windows regression: **476 passed, no skips**, including 18 new targeted contracts. Historical 458-case logs and earlier EXEs belong to an older digest. Existing EXEs were not reused as current evidence; no new EXE is distributed by this source-only delivery.

Source Alpha is prepared locally for owner review; no repository is claimed to be public. Native 100%/200% DPI, controlled proxy writes/restores, UAC/elevated WFP, clean Windows VM, signing and remote CI remain unverified. Formal Release Gate remains closed.
